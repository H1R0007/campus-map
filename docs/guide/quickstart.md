# Быстрый старт

Запуск навигатора и редактора на локальной машине.

## Что понадобится

- **Node 22** и **pnpm 9**. Сборка проверяется также на Node 20. Версия pnpm зафиксирована полем `packageManager`, поэтому активировать её нужно через corepack — локальная версия 8 или 10 иначе может иначе обработать lock-файл:

```bash
corepack enable
corepack prepare pnpm@9.0.0 --activate
```

- Git. Больше ничего: база данных, сервер и сборка данных не нужны — датасет лежит в репозитории статическими файлами.

## Запуск

```bash
git clone https://github.com/H1R0007/campus-map.git
cd campus-map
pnpm install     # зависимости + линковка workspace-пакетов
pnpm dev         # оба приложения
```

`pnpm dev` сначала собирает пакеты `core` и `mapkit`, затем поднимает приложения. Отдельная сборка ядра перед запуском не нужна.

| Адрес | Что открывается |
| --- | --- |
| `http://localhost:3000` | навигатор |
| `http://localhost:3001` | редактор разметки |
| `http://localhost:3002` | прототип экскурсий 360°, отдельной командой (см. ниже) |
| `http://localhost:3003` | эта документация (`pnpm docs:dev`) |

Серверы слушают `0.0.0.0`, поэтому навигатор открывается с телефона в той же сети по адресу компьютера. Это основной способ проверки на реальном устройстве.

## Проверка после запуска

Данные в `data/` — сгенерированный тестовый кампус: три корпуса, шесть этажей, схематичные SVG-планы, полная привязка к метрике. Все сценарии работают на этих данных.

Навигатор (`http://localhost:3000`):

1. Найти «А-305». Поиск обрабатывает опечатки, латиницу вместо кириллицы и неверную раскладку.
2. Построить маршрут от «Парковки» до «А-305». Маршрут проходит по территории, через вход и по лестнице; в карточке — время в пути, в шагах — повороты у ориентиров и фото.
3. Включить ограничение «без лестниц» и повторить. Часть маршрутов станет недоступна, навигатор предложит разрешить лестницы.
4. Открыть `?at=a1_entrance` в адресе. Так работает QR-код у двери: начальная точка маршрута — «вы здесь».

Редактор (`http://localhost:3001`):

1. Нажать **«Учебная копия»** в шапке. Дальнейшие действия, включая «Сохранить», не изменяют `data/`.
2. Открыть «Корпус А, этаж 1», поставить точку инструментом «Точка» (клавиша `N`), отменить её через `Ctrl+Z`.
3. Открыть «Проверка → Готовность»: пятнадцать проверок по данным, у невыполненной есть кнопка перехода к месту исправления.

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | оба приложения в режиме разработки |
| `pnpm build` | пакеты в `dist`, приложения в `apps/*/dist`, документация в `docs/dist` |
| `pnpm typecheck` | проверка типов во всех пакетах |
| `pnpm lint` | ESLint (плоский конфиг в корне) |
| `pnpm test` | тесты ядра, навигатора, редактора; сверка `dist/data` с `data/`; смоук-тесты раздачи |
| `pnpm check:browser` | сценарии в настоящем браузере — после `pnpm build`, выполняется минуты |
| `pnpm docs:dev` / `pnpm docs:build` | эта документация |
| `pnpm clean` / `pnpm clean:all` | убрать `dist` и `*.tsbuildinfo` / вместе с `node_modules` |

Полный набор проверок: `pnpm build && pnpm typecheck && pnpm lint && pnpm test`. Те же команды выполняет CI.

## Ошибки при первом запуске

**Правка ядра не видна в приложении.** `@campus-map/core` и `@campus-map/mapkit` подключаются собранными, через `dist`, а не исходниками. После правки ядра его нужно пересобрать:

```bash
pnpm --filter @campus-map/core build     # разово
pnpm --filter @campus-map/core dev       # или watch-режим на время работы
```

**Редактор пишет прямо в `data/`.** «Сохранить» записывает файлы в `data/`, изменения забирает git. Для проверки незнакомых действий используется «Учебная копия».

**Копия `data/` внутри приложений.** Каталог раздаёт Vite-плагин; `public/data` сделал бы Vite вторым писателем в `dist/data/**`. Подробнее — [Зависимости и данные](../architecture/dependencies.md).

## Экскурсии 360° (прототип)

Отдельное приложение, в продукт не входит и не разворачивается:

```bash
pnpm --filter @campus-map/tour-lab dev              # http://localhost:3002
pnpm --filter @campus-map/tour-lab samples          # открытые снимки Poly Haven, ~115 МБ, один раз
```

Без `samples` работают заглушки-компасы: по ним видно, верно ли расставлены стрелки. Решения по прототипу — в `DECISIONS.md`, запись 90.
