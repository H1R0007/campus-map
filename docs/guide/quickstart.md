# Быстрый старт

Цель страницы — запустить оба приложения и увидеть карту. Пять минут, ничего не настраивая.

## Что понадобится

- **Node 22** (на Node 20 тоже работает — на нём собирают на основной машине разработки) и **pnpm 9**. Версия pnpm зафиксирована полем `packageManager`, поэтому активировать её лучше через corepack — иначе локальная версия 8 или 10 может повести себя иначе с lock-файлом:

```bash
corepack enable
corepack prepare pnpm@9.0.0 --activate
```

- Git. Больше ничего: база данных, сервер и сборка данных не нужны — датасет лежит в репозитории статическими файлами.

## Запуск

```bash
git clone https://github.com/H1R0007/campus-map.git
cd campus-map
pnpm install     # зависимости + линковка workspace-пакетов
pnpm dev         # оба приложения
```

`pnpm dev` сначала собирает пакеты (`core` и `mapkit`), потом поднимает приложения — отдельно собирать ядро не нужно.

| Адрес | Что открывается |
| --- | --- |
| `http://localhost:3000` | навигатор — то, что видит студент |
| `http://localhost:3001` | редактор — рабочее место разметки |
| `http://localhost:3002` | прототип экскурсий 360°, отдельной командой (см. ниже) |
| `http://localhost:3003` | эта документация (`pnpm docs:dev`) |

Серверы слушают `0.0.0.0`, поэтому с телефона в той же сети навигатор открывается по адресу компьютера — это штатный способ проверять его на настоящем устройстве.

## Первое, что стоит сделать руками

Данные в `data/` — сгенерированный **тестовый** кампус: три корпуса, шесть этажей, схематичные SVG-планы, полная привязка к метрике. На нём работают все сценарии.

В навигаторе (3000):

1. Найдите «А-305» — поиск прощает опечатки, латиницу вместо кириллицы и неверную раскладку.
2. Постройте маршрут от «Парковки» до «А-305». Маршрут пойдёт по территории, через вход, по лестнице; в карточке будет время в пути, в шагах — повороты у ориентиров и фото.
3. Включите ограничение «без лестниц» и повторите: часть маршрутов исчезнет, а навигатор предложит разрешить лестницы.
4. Откройте `?at=a1_entrance` в адресе — так работает QR-код у двери: «вы здесь» в этой точке.

В редакторе (3001):

1. Нажмите **«Учебная копия»** в шапке — дальше можно делать что угодно, включая «Сохранить», настоящий `data/` не изменится.
2. Откройте «Корпус А, этаж 1», поставьте точку инструментом «Точка» (клавиша `N`), отмените её через `Ctrl+Z`.
3. Загляните в «Проверка → Готовность»: пятнадцать проверок по данным, у невыполненной — кнопка туда, где это исправляют.

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | оба приложения в режиме разработки |
| `pnpm build` | пакеты в `dist`, приложения в `apps/*/dist`, документация в `docs/dist` |
| `pnpm typecheck` | проверка типов во всех пакетах |
| `pnpm lint` | ESLint (плоский конфиг в корне) |
| `pnpm test` | тесты ядра, навигатора, редактора; сверка `dist/data` с `data/`; смоук-тесты раздачи |
| `pnpm check:browser` | сценарии в настоящем браузере — после `pnpm build`, идёт минуты |
| `pnpm docs:dev` / `pnpm docs:build` | эта документация |
| `pnpm clean` / `pnpm clean:all` | убрать `dist` и `*.tsbuildinfo` / вместе с `node_modules` |

Проверять всё сразу: `pnpm build && pnpm typecheck && pnpm lint && pnpm test`. Ровно это делает CI.

## Три вещи, на которых спотыкаются в первый день

**Правка ядра не видна в приложении.** `@campus-map/core` и `@campus-map/mapkit` подключаются собранными — через `dist`, а не исходниками. После правки ядра его нужно пересобрать:

```bash
pnpm --filter @campus-map/core build     # разово
pnpm --filter @campus-map/core dev       # или watch-режим на время работы
```

**Редактор пишет прямо в `data/`.** Это задумано: команда разметки запускает редактор из репозитория, «Сохранить» пишет файлы в `data/`, а забирает их git. Если пробуете незнакомое — «Учебная копия», а не настоящие данные.

**Не копируйте `data/` внутрь приложений.** Каталог раздаёт Vite-плагин, а `public/data` сделал бы Vite вторым писателем в `dist/data/**`. Подробнее — [Зависимости и данные](/architecture/dependencies).

## Экскурсии 360° (прототип)

Отдельное приложение, не часть продукта и не разворачивается:

```bash
pnpm --filter @campus-map/tour-lab dev              # http://localhost:3002
pnpm --filter @campus-map/tour-lab samples          # открытые снимки Poly Haven, ~115 МБ, один раз
```

Без `samples` работают заглушки-компасы — по ним видно, верно ли расставлены стрелки. Смысл и решения — в `DECISIONS.md`, запись 90.
