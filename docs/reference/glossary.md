# Термины

Значения терминов в этом проекте. Интерфейс и данные местами называют одно и то же по-разному — соответствие зафиксировано в [Как устроена документация](../meta/how-we-write.md#термины).

| Термин | Значение |
| --- | --- |
| **Узел** (точка) | Место на плане, через которое возможен проход: дверь аудитории, поворот коридора, лестничная площадка, вход. В данных и коде — узел, в интерфейсе редактора — точка |
| **Связь** (`neighbors`) | Проход между двумя узлами одного этажа. Двусторонняя |
| **Переход** (`transitions.json`) | Связь узлов разных этажей или корпусов: вход, лестница, лифт, мост |
| **Портал** | Узел, участвующий в переходах. Поле `isPortal` вычисляется, а не задаётся |
| **Алиас** | Название узла. Единственный способ найти место из интерфейса |
| **Вид места** | Категория места: столовая, туалет, гардероб. Задаётся каталогом `place-kinds.json` |
| **Ориентир** | Объект у точки, по которому место узнают на месте: кофейный автомат, турникеты |
| **Датасет** | Каталог `data/` целиком: планы, графы, переходы, алиасы, каталог видов |
| **План** | Изображение этажа или территории: `map.png`, `map.svg`, `map.jpg` или `map.webp` |
| **Размещение** (`placement`) | Положение корпуса на территории: масштаб, сдвиг, поворот, высоты этажей |
| **Привязка** | Наличие `placement` у территории и каждого этажа. Бывает полной или отсутствует |
| **Метрический режим** | Привязка полная: координаты в метрах, стоимость шага в секундах, есть время в пути |
| **Пиксельный режим** | Привязка неполная: координаты в пикселях плана, время в пути не показывается |
| **Совмещение** | Положение этажа относительно этажа входа — только этаж относительно этажа, не корпус относительно корпуса |
| **Этаж входа** (`entranceFloor`) | Этаж, который открывается при выборе корпуса на карте кампуса |
| **Холст кампуса** | Вид карты, где территория и этажи всех корпусов стоят в пространстве в метрах |
| **Готовность карты** | Пятнадцать проверок данных в редакторе: что ещё не хватает навигатору |
| **Учебная копия** | Копия датасета внутри редактора: сохранение в неё не меняет `data/` |
| **Сценарий** | Проверка в настоящем браузере: щелчки, клавиши, ожидаемый результат |
| **Смоук-тест** | Проверка раздачи собранного приложения по HTTP: коды ответов, наличие файлов |
| **Warning загрузчика** | Сообщение о некорректной записи данных: запись отброшена, остальное загружено |

## Термины вне проекта

| Термин | Значение |
| --- | --- |
| **PWA** | Веб-приложение, которое ставится на устройство и работает без сети за счёт service worker |
| **Service worker** | Скрипт в браузере, перехватывающий запросы и отдающий их из кэша |
| **A\*** | Алгоритм поиска кратчайшего пути по графу с оценкой остатка |
| **Эвристика** | Оценка стоимости пути до цели; для оптимальности не должна переоценивать остаток |
| **Согласованная эвристика** | Оценка, для которой на любом ребре `h(a) ≤ cost(a, b) + h(b)` |
| **Data URL** | Адрес вида `data:image/svg+xml,…`, содержащий данные внутри себя, без запроса по сети |
| **Монорепо** | Один репозиторий с несколькими пакетами и приложениями |
| **Workspace** | Набор пакетов, связанных менеджером пакетов в один проект (здесь pnpm) |
