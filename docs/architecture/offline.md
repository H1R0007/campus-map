# Офлайн-работа и обновление

Навигатор устанавливается на телефон как PWA и работает без связи. Это не украшение: в коридорах вуза связь бывает плохой, а карта нужна именно там.

## Что кэшируется

Два уровня кэша, и они устроены по-разному.

**Precache — оболочка приложения.** HTML, JS, CSS, значки, шрифты и иконки PWA попадают в кэш при установке service worker. Список задан шаблонами в `apps/viewer/vite.config.ts`, файлы датасета в него не входят.

**Runtime-кэш — данные.** Планы этажей, фото и JSON кэшируются при первом обращении, каждое своей стратегией:

| Что | Стратегия | Кэш | Почему так |
| --- | --- | --- | --- |
| фото точек | `CacheFirst` | `campus-photos`, до 150 файлов, 90 дней | имя фото — отпечаток содержимого, файл не устаревает |
| планы этажей и территории | `CacheFirst` | `campus-maps`, до 200 файлов, 90 дней | меняются редко, а без плана навигатор бесполезен |
| JSON датасета | `StaleWhileRevalidate` | `campus-data`, до 500 файлов, 30 дней | данные правят, поэтому кэш отдаётся сразу и обновляется в фоне |

Фото получает отдельный кэш и правило раньше правил планов: workbox берёт первое подходящее правило, а в общем кэше сотня просмотренных фото вытеснила бы планы этажей.

Датасет не попадает в установочный пакет ни при каких шаблонах (`globIgnores`): тестовые планы весят около 2,3 МБ, официальные будут больше.

## Первое открытие

При первой установке service worker появляется уже после того, как страница загрузила данные и планы. Эти запросы шли мимо него и в кэш не попали — без связи навигатор не открылся бы до второго визита.

Поэтому:

1. `clientsClaim: true` — service worker сразу берёт открытую страницу под управление.
2. `pwa/warmCache.ts` — когда управление получено, приложение повторно запрашивает те файлы данных, которые страница уже загружала: JSON и открытые планы. Теперь запросы идут через service worker и попадают в кэш.

## Обновление по согласию

Новая версия приложения или данных приходит новым service worker. Он устанавливается в фоне и ждёт (`waiting`), пока человек не нажмёт «Обновить».

| Что | Как |
| --- | --- |
| Режим | `registerType: 'prompt'` — service worker не активируется сам |
| Регистрация | своя, в `pwa/registerServiceWorker.ts`; `injectRegister: false` |
| Проверка обновлений | раз в час, пока приложение открыто |
| Применение | сообщение `SKIP_WAITING`, затем перезагрузка по событию `controllerchange` |

Прежний режим `autoUpdate` перезагружал страницу сам — в том числе посреди маршрута. Своя регистрация вместо модуля плагина нужна потому, что модулю требуется `workbox-window`, а здесь достаточно стандартного API.

Первая установка обновлением не считается: если управляющего service worker ещё нет, ждущая версия не предлагается.

## Прогрев маршрута

Пока связь есть, приложение заранее запрашивает то, что понадобится в пути:

- `usePrefetchRoutePlans` — планы этажей, по которым проходит построенный маршрут;
- `usePrefetchRoutePhotos` — фото шагов.

Иначе первый поворот маршрута в подвале показывал бы пустое место вместо плана.

## Ограничения

- Service worker работает только в прод-сборке: в dev файла `sw.js` нет, регистрация дала бы 404.
- Офлайн-доступна только та часть карты, которую человек уже открывал или которая была прогрета маршрутом. Весь кампус заранее не скачивается.
- Кэш привязан к адресу: смена базового пути развёртывания (`CAMPUS_BASE_PATH`) — это другое приложение для браузера, кэш придётся набрать заново.

## Как проверить

```bash
pnpm build                                   # без прод-сборки service worker не работает
pnpm --filter @campus-map/viewer preview
```

1. Открыть приложение, построить маршрут, пройти по шагам.
2. В инструментах разработчика: Application → Service Workers — убедиться, что worker активен, и включить Offline.
3. Перезагрузить страницу: карта, планы и маршрут должны открыться.
4. Собрать новую версию, обновить страницу: должно появиться предложение обновления, а не мгновенная перезагрузка.

Автоматически это проверяет сценарий `viewerOffline` в `tooling/browser/scenarios`, а правило кэширования фото и планов закреплено тестами навигатора.
