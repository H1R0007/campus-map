# Карта репозитория

Монорепо на pnpm + turborepo. Всё, что нужно запустить, — в одном клоне: датасет, приложения, скрипты, проверки.

```text
campus-map/
├── data/                  датасет: единственный источник истины о кампусе
├── apps/
│   ├── viewer/            навигатор — то, что видит студент
│   ├── editor/            редактор разметки — рабочее место команды
│   └── tour-lab/          прототип экскурсий 360°, не разворачивается
├── packages/
│   ├── core/              доменное ядро: формат, граф, поиск, проекция
│   └── mapkit/            общая обвязка Leaflet-карты
├── tooling/               скрипты на Node: сборка данных, проверки, сценарии
├── docs/                  эта документация
├── README.md              короткий вход в проект
├── DECISIONS.md           журнал архитектурных решений
└── data-sources/          присланные оригиналы планов (в git не попадает)
```

## Где что лежит

| Каталог | Что там | Когда идти |
| --- | --- | --- |
| `data/` | планы, графы, переходы, алиасы, каталог видов, фото тестового кампуса | разметка, вопросы «почему на карте нет точки» |
| `packages/core/src/types/` | контракт данных: `MapNode`, `Transition`, `Dataset`, `PlaceKind`… | новое поле данных |
| `packages/core/src/dataset/` | загрузчик, нормализация, раскладка путей, HTTP-источник | «данные читаются не так» |
| `packages/core/src/graph/` | неизменяемый `Graph`, индекс смежности, связность | выборки узлов, вопрос «связен ли граф» |
| `packages/core/src/pathfinding/` | A*, модель стоимости, время в пути | маршрут, веса, «почему повёл через лестницу» |
| `packages/core/src/projection.ts` | привязка планов к территории, мировые координаты | метры, повороты, высоты этажей |
| `packages/core/src/aliases/` | нечёткий поиск по названиям | «не находит аудиторию» |
| `packages/core/src/turns.ts` | «налево / направо / прямо» по линии маршрута | инструкции у ориентиров |
| `packages/core/src/panoramas/` | формат панорам, стрелки между снимками | экскурсии 360° |
| `packages/mapkit/src/` | `PixelMap`, `WorldMap`, `PlacedPlan`, камера, поворот, значки переходов | поведение карты как таковое |
| `apps/viewer/src/components/Map/` | слои навигатора: точки, маршрут, порталы, холст | «на карте не видно…» |
| `apps/viewer/src/components/UI/` | панели, карточка места, шаги, поиск, темы | интерфейс навигатора |
| `apps/viewer/src/utils/routeInstructions.ts` | пошаговые инструкции | текст шага |
| `apps/viewer/src/i18n/` | словари `ru.ts`, `en.ts`, список языков | новая строка, новый язык |
| `apps/viewer/src/pwa/` | регистрация service worker, прогрев кэша | офлайн, обновление |
| `apps/editor/src/stores/editor/` | срезы стора: данные, правка, история, размещение, окна | действия редактора |
| `apps/editor/src/stores/historyStore.ts` | контракт отмены/повтора | новое отменяемое действие |
| `apps/editor/src/components/Layout/` | шапка, дерево, инструменты, свойства, вкладки | раскладка редактора |
| `apps/editor/src/import/` | чтение PDF/DXF/TIFF/ZIP, догадки, обрезка, готовый план | мастерская листов |
| `apps/editor/src/overlay/` | поиск контура здания, силуэты, наложение | «план не совпал» |
| `apps/editor/src/utils/readiness.ts` | пятнадцать проверок «Готовности карты» | «что ещё нужно навигатору» |
| `tooling/vite-plugin-campus-data.mjs` | раздача и запись `data/`, учебная копия, фото | данные отдаются не так, сохранение |
| `tooling/browser/scenarios/` | сценарии в браузере (28 редактора, 10 навигатора) | правка текста интерфейса |
| `tooling/generate-test-data.mjs` | генератор тестового кампуса | пересборка тестовых данных |

## Куда идти с задачей

| Задача | Начинать с |
| --- | --- |
| Добавить корпус или этаж | [рецепт](/recipes/add-building) и `apps/editor/src/stores/editor/structureSlice.ts` |
| Новое поле в данных | `packages/core/src/types/`, `dataset/loader.ts`, `apps/editor/src/utils/exportData.ts`, тест — все четыре места |
| Поправить маршрут или веса | `packages/core/src/pathfinding/costModel.ts`, `astar.ts` |
| Изменить пошаговую инструкцию | `apps/viewer/src/utils/routeInstructions.ts` + оба словаря |
| Добавить строку интерфейса | `apps/viewer/src/i18n/ru.ts` и `en.ts` (второй не даст забыть) + сценарии в браузере |
| Поправить поведение карты | `packages/mapkit/src/mapFrame.tsx`, `PixelMap.tsx`, `WorldMap.tsx` |
| Новое действие в редакторе | срез в `apps/editor/src/stores/editor/` + член `HistoryEntry` в `historyStore.ts` + тест `tests/history.test.ts` |
| Понять, почему так, а не иначе | `DECISIONS.md`, поиск по номеру из комментария в коде |

## Что не входит в git

Репозиторий публичный, поэтому часть материалов живёт рядом с ним:

| Что | Где | Почему |
| --- | --- | --- |
| Оригиналы присланных планов | `data-sources/` (локально) | в оригиналах бывает лишнее для публикации; в `data/` лежит уже готовый план |
| Настоящие фото точек | общая папка, путь в `CAMPUS_PHOTOS_DIR` | фото людей и помещений вуза нельзя публиковать; папка одна на всех, имена — отпечатки содержимого |
| Снимки 360° | `.local/panoramas` или `CAMPUS_PANORAMAS_DIR` | тяжёлые, не для git |
| Синтетический кампус для нагрузочных проверок | `.local/campus-*` | генерируется заново одной командой |

## Файлы, которые правят чаще всего

| Файл | Зачем |
| --- | --- |
| `data/aliases.json` | названия помещений — единственный способ найти точку из интерфейса |
| `data/transitions.json` | связность этажей и корпусов |
| `data/place-kinds.json` | виды мест: кнопки, значки, слова поиска |
| `data/buildings/<id>/meta.json` | этажи, масштаб, размещение корпуса на территории |
| `package.json`, `turbo.json` | команды и порядок сборки |
| `.github/workflows/ci.yml` | что проверяется на каждом пуше |

> Данные в `data/` собраны генератором (`tooling/generate-test-data.mjs`). Правка графа руками перезапишется следующим запуском генератора — править нужно описание кампуса в `tooling/lib/test-campus.mjs`. Редактор тоже пишет в `data/`, и это нормально: пока данные тестовые, генератор просто не запускают.
