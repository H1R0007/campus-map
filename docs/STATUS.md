   из навигатора в очередь правок редактора.
4. Несколько разметчиков: сейчас сохранение — один человек на одной машине.
5. Удалить тестовый кампус, когда появятся настоящие данные (в git не класть).

## Как проверять

`pnpm build && pnpm typecheck && pnpm lint && pnpm test`, затем
`pnpm check:browser` (23 сценария редактора, 9 навигатора; полный прогон на
ПК владельца — около 12 минут). В облаке браузер —
`CAMPUS_BROWSER=/opt/pw-browsers/chromium`. Сценарии prod-сборки берут `dist`
— после правок пересобрать.

## Что помнить

- Владелец пишет по-русски; интерфейс — по словарю (запись 58).
- Работа идёт и в облаке, и на ПК владельца. Перед началом — `git fetch` и
  сверка: нет ли на ПК незакоммиченного, не ушёл ли `master` вперёд.
- Сценарии в браузере ищут тексты интерфейса: меняешь фразу — ищи её в
  `tooling/browser/scenarios` и меняй там же.
- Репозиторий публичный: настоящих адресов и планов вуза в git не класть.
- Старые планы вуза (2022): PDF по корпусу, поэтажные планы с экспликацией,
  1:200, красные «номер / площадь». О виде новых планов ничего не говорят.
