# Виды мест (`place-kinds.json`)

Вид места отвечает на вопрос «что это за место»: по нему навигатор ищет ближайшее место нужного вида, рисует значок и показывает быструю кнопку, а редактор решает, как назвать новую точку и соединять ли её с соседями.

Какие виды бывают, решает **каталог в данных, а не код**: разметчик заводит свой вид прямо в редакторе («Медпункт», «Банкомат»), и навигатор сразу показывает для него кнопку, значок и находит его по словам поиска (запись 44).

```json
{
  "kinds": [
    {
      "id": "toilet",
      "name": "Туалет",
      "nameEn": "Toilet",
      "icon": "tabler:badge-wc",
      "iconImage": "data:image/svg+xml,%3Csvg…",
      "color": "place",
      "searchTerms": ["туалет", "уборная", "wc", "toilet"],
      "place": true,
      "quick": true,
      "namePattern": "Туалет",
      "connect": true
    }
  ]
}
```

## Поля вида

| Поле | Смысл |
| --- | --- |
| `id`, `name`, `nameEn` | id в данных (латиницей, без пробелов), название по-русски и по-английски |
| `icon` | ссылка на значок из набора редактора: `tabler:<имя>`, `custom` или прежнее имя |
| `iconImage` | сама картинка адресом `data:` (SVG или PNG, до 64 КБ); по ней рисуют и редактор, и навигатор — навигатору библиотека значков не нужна |
| `color` | цвет точки в редакторе — **имя из палитры**, а не код цвета: цвета объявлены токенами в одном месте |
| `searchTerms` | слова, по которым ищут все места вида: «поесть», «столовка», «canteen» |
| `place` | вид — место быстрого поиска: точки получают вид места (`category`), навигатор ищет ближайшее |
| `quick` | быстрая кнопка в навигаторе; порядок кнопок — порядок каталога |
| `namePattern` | шаблон названия: `{корпус}`, `{этаж}` подставляет редактор, `{номер}` — место для курсора |
| `connect` | соединять новую точку с ближайшей точкой плана |
| `chain` | вести линию: каждая следующая точка соединяется с предыдущей, как ломаная (так размечают коридоры) |

## Как это работает на практике

- **Нет своего каталога** — действует затравка ядра `DEFAULT_PLACE_KINDS`: коридор, помещение и три места — туалет (`toilet`), столовая (`food`), гардероб (`cloakroom`).
- **Один щелчок кистью** подставляет название по шаблону, связь с ближайшей точкой и вид места для навигатора (записи 40, 44).
- **Цифры 1–8** в редакторе выбирают вид и берут инструмент «Точка».
- **Новый вид обрабатывается так же, как встроенный.** Код навигатора и формат узлов не меняются: вид заполняет существующие поля.
- **В каталоге данных лежит и `iconImage`.** Навигатор читает каталог сам: кнопка, значок и слова поиска приходят из данных.

## Чего в каталоге нет

- **Переходов.** Лестница, лифт, вход и мост — это смена этажа или корпуса; у них свой инструмент «Переход» и своя логика. Вид места описывает только «что это», а не «куда ведёт».
- **Выхода.** Выход — это вход в корпус, заведённый переходом `entrance`; навигатор находит ближайшую дверь сам. Прежняя отметка `"category": "exit"` снимается загрузчиком с объяснением.
