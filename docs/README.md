# Документация проекта

**Карта кампуса** — навигатор по корпусам учебного заведения и редактор разметки, над общим доменным ядром и одним датасетом.

Документация — обычные Markdown-файлы, которые читаются прямо здесь, на GitHub, без сборки. Ниже — карта всех страниц с описаниями, в порядке чтения. Правила правки — в [Как устроена эта документация](meta/how-we-write.md); формы выпуска (сайт, один файл для передачи) — в [Три формы документации](meta/transfer.md).
