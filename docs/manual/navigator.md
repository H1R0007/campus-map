# Навигатор: как найти аудиторию

Руководство для студента, сотрудника и гостя. Открывается в браузере телефона или компьютера; на телефон устанавливается как приложение и работает без интернета.

## Найти место

1. Нажать на строку поиска «Найти аудиторию или место».
2. Набрать номер или название: «305», «А-305», «библиотека».
3. Выбрать нужное из подсказок.

Поиск не требует точного ввода:

| Что набрали | Что найдётся |
| --- | --- |
| `а-305`, `А305`, `а 305` | «А-305» |
| `305` | «А-305» |
| `a-305` (латиницей) | «А-305» |
| `,b,kbjntrf` (не та раскладка) | «Библиотека» |
| `бибилотека` (опечатка) | «Библиотека» |
| `столовка`, `поесть` | все места вида «Столовая» |
| `Library` | «Библиотека» |

Опечатки прощаются в зависимости от длины слова: одна в слове из 4–5 букв, две до 8, три в более длинных. В запросе короче четырёх букв опечатки не прощаются — иначе поиск находил бы лишнее.

Если название есть у нескольких помещений («Столовая» в каждом корпусе), подсказки показывают их все с корпусом и этажом. Набрать такое название целиком и надеяться на единственный результат нельзя: навигатор покажет список.

## Быстрые кнопки

Над списком — кнопки «Туалет», «Столовая», «Гардероб», «Ближайший выход». Они ведут к ближайшему месту этого вида оттуда, где вы стоите.

Если место, откуда вы идёте, не задано, навигатор спросит: «Где вы сейчас?». Проще всего отсканировать QR-код на табличке у входа или лестницы — он и есть ответ на этот вопрос.

## Маршрут

1. Указать начало — поиском, быстрой кнопкой или QR-кодом.
2. Указать конец — поиском или карточкой места («Маршрут сюда»).
3. В карточке маршрута: время в пути, длина, этажи.

Что показывает карточка:

| Строка | Значение |
| --- | --- |
| «Маршрут · ~4 мин» | время в пути |
| «Откуда: Главный вход» | начало маршрута |
| «Начать» | пошаговая навигация |
| «Шаги» | список шагов сразу, без пошагового режима |
| «Ограничения» | «Без лестниц», «Предпочитать лифт» |
| «Поделиться маршрутом» | ссылка на этот маршрут |

### Если маршрут не найден

Под карточкой будет причина:

| Причина | Что значит |
| --- | --- |
| начальная точка не найдена | такой точки нет на карте |
| конечная точка не найдена | такой точки нет на карте |
| при выбранных ограничениях точки не связаны | мешает запрет: например, «Без лестниц» |
| поиск прерван, попробуйте другие точки | ошибка в данных |

Если мешает запрет лестниц, в сообщении будет кнопка «Разрешить лестницы».

## Пошаговая навигация

Кнопка «Начать» открывает шаги по одному:

- «Шаг 3 из 8» — где вы в маршруте;
- «Далее», «Предыдущий шаг» — перелистывание;
- «Показать шаг на карте» — карта переходит к этому шагу и открывает нужный этаж сама;
- в шапке — «осталось ~2 мин»;
- экран не гаснет, пока идёт навигация.

Шаги бывают такие:

| Шаг | Пример |
| --- | --- |
| пеший участок | «Дойдите до лифта» |
| поворот у ориентира | «У кофейного автомата поверните налево» |
| переход | «Поднимитесь на лифте — Этаж 5» |
| прибытие | «Вы на месте» |

Ориентиры — кофейный автомат, турникеты, стенд — указаны в шагах не для красоты: по ним видно, что вы идёте правильно. Фотографии в шагах показывают дверь или ориентир.

После последнего шага — «Вы на месте» и две кнопки: «Обратно» и «К выходу».

## Карта

| Действие | Как |
| --- | --- |
| Приблизить и отдалить | колесо мыши, щипок двумя пальцами, кнопки на карте |
| Двигать карту | перетаскивание |
| Открыть корпус | приблизить: вместо крыши проявится этаж |
| Вернуться ко всему кампусу | кнопка «Вернуться к карте кампуса» |
| Повернуть карту на север | кнопка поворота |
| Увидеть этаж целиком | «Показать план целиком» |

Участки маршрута на других этажах показаны пунктиром: они есть в маршруте, но с этого плана их не видно.

## QR-код у двери

На табличках у входов и лестниц есть QR-код. Он открывает навигатор с началом маршрута в этой точке — «вы здесь». Внутри здания это точнее любого другого способа: спутниковая геолокация в помещении не работает.

Если код устарел (табличку повесили до переразметки), навигатор скажет, что точки больше нет, и предложит поиск.

## Без интернета

Навигатор работает без связи, если им уже пользовались:

- оболочка приложения и открытые планы сохранены;
- планы и фото этажей маршрута загружаются заранее, пока связь есть.

Без связи доступно то, что вы уже открывали. Если план этажа не сохранён, на нём будет написано «План этого этажа не сохранён — нужна связь».

Когда связь пропадает, сверху появляется сообщение: «Нет связи — навигатор работает без интернета».

## Обновление

Новая версия карты приходит сама и ждёт согласия: «Карта обновилась» с кнопками «Обновить» и «Обновить позже». Нажатие «Обновить» перезагружает приложение — это делается специально, чтобы обновление не случилось посреди маршрута.

## Язык

Переключатель языка — в шапке. Если на табличке или в ссылке указан язык (`?lang=en`), навигатор откроется на нём.

Названия помещений переводятся, если перевод есть в данных; иначе показывается русское название. Номер аудитории одинаков на всех языках.

## Установка на телефон

1. Открыть адрес навигатора в браузере телефона.
2. В меню браузера выбрать «Установить приложение» или «На экран Домой».
3. Запускать с иконки: приложение откроется без адресной строки и будет работать без связи.

## Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| Карта пустая | нет связи и этаж не открывался раньше: нужна связь хотя бы один раз |
| Поиск не находит аудиторию | набрать номер без буквы корпуса или проверить раскладку |
| Нет времени в пути | карта не привязана к метрике: сообщить тому, кто ведёт карту |
| Маршрут ведёт странно | проверить ограничения: возможно, включено «Без лестниц» |
| QR-код не открывает точку | табличка устарела: сообщить тому, кто ведёт карту |
