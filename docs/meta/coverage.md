# Карта покрытия

Состояние документации: какие темы закрыты, какие описаны частично и чего нет. Страница служит списком следующей работы, а не отчётом о проделанном.

Статусы: **готово** — по странице можно работать; **частично** — описано основное, отдельных случаев нет; **план** — темы нет.

## Чего нет

Темы, которые сознательно не описаны или описаны частично. Список нужен, чтобы отсутствие раздела не выглядело недосмотром.

| Тема | Почему | Когда появится |
| --- | --- | --- |
| Учебник «с нуля до маршрута» | Быстрый старт и руководства закрывают задачу короче; отдельный учебник дублировал бы их | если появятся внешние читатели без доступа к репозиторию |
| Прототип панорам (`apps/tour-lab`) | Не входит в поставку, интерфейс меняется | после решения о панорамах, запись 90 |
| Расширение карты за пределы кампуса | Вопрос открыт | — |
| Схемы и рисунки | Схемы в markdown быстро расходятся с кодом; связи описаны таблицами | если появятся устойчивые схемы данных |
| Справочник по каждому компоненту интерфейса | Компоненты меняются чаще контрактов; описаны экраны и действия | — |
| Перевод документации на английский | Интерфейс двуязычный, документация — для тех, кто ведёт карту | по запросу |

## Откуда берётся материал

| Источник | Роль | Что делать при расхождении |
| --- | --- | --- |
| код | истина о поведении | править документацию |
| `DECISIONS.md` | причины ограничений | не пересказывать, ссылаться по номеру |
| `README.md` | короткий вход в проект | подробности переносить сюда, а не наоборот |
| `docs/STATUS.md` | где мы и что дальше | обновляет тот, кто заканчивает работу |
| тесты и сценарии | проверяемое поведение | расхождение означает ошибку в документации |

## Как поддерживать страницу

Страница обновляется вместе с документацией, а не отдельным проходом:

1. Добавили страницу — строка в таблицу своего раздела, `pnpm docs:map`.
2. Описали тему из «Чего нет» — перенести строку в раздел, причину убрать.
3. Заметили, что страница расходится с кодом, — статус **частично** и строка в ближайшие.

Строка со статусом **готово** означает, что страницу проверили по коду или по прогону, а не что её написали.
