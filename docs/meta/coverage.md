# Карта покрытия

Что уже описано, что впереди и откуда берётся материал. Страница нужна по двум причинам: чтобы не писать одно и то же дважды и чтобы было видно, какую тему ещё никто не закрыл.

Статусы: **готово** — страницу можно читать и по ней работать; **в работе** — есть каркас, не хватает деталей; **план** — темы нет.

## Пользовательская документация

Отдельная ветка работы, ещё не начата. Три разных читателя:

| Читатель | Что ему нужно | Материал |
| --- | --- | --- |
| Студент и сотрудник | найти аудиторию, построить маршрут, читать шаги, QR-коды, офлайн, язык | навигатор, README «Ссылки на навигатор» |
| Разметчик | планы из файлов, точки, связи, переходы, размещение, проверки, сохранение | README «Как работать в редакторе», справка F1 в редакторе |
| Администратор и ИТ вуза | развернуть, обновить данные, ограничения, кто за что отвечает | [Сборка и развёртывание](/operations/build-deploy) |

## Откуда берётся материал

| Источник | Роль | Что делать при расхождении |
| --- | --- | --- |
| код | истина о поведении | править документацию |
| `DECISIONS.md` | причины ограничений | не пересказывать, ссылаться по номеру |
| `README.md` | короткий вход в проект | подробности переносить сюда, а не наоборот |
| `docs/STATUS.md` | где мы и что дальше | обновляет тот, кто заканчивает работу |
| тесты и сценарии | проверяемое поведение | тест — аргумент в пользу документации, а не наоборот |
