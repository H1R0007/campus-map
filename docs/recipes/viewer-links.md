# Ссылки и QR-коды

Адрес навигатора умеет три вещи: открыть маршрут, поставить точку «вы здесь» и переключить язык. Этого достаточно, чтобы сделать QR-код у двери или переслать маршрут коллеге.

## Параметры

| Параметр | Что делает |
| --- | --- |
| `?at=<узел>` | «вы здесь»: начало маршрута в этой точке, карта показывает её этаж |
| `?from=<узел>` | начало маршрута |
| `?to=<узел>` | конец маршрута |
| `?lang=ru` \| `?lang=en` | язык интерфейса |

Значение — id узла (`a1_room101`) или название, если оно указывает ровно на одно помещение. Название удобнее набирать руками, id надёжнее: он не зависит от переименования.

Примеры:

```text
https://map.example.edu/?at=a1_entrance          # табличка у входа
https://map.example.edu/?to=Библиотека           # ссылка «как дойти до библиотеки»
https://map.example.edu/?from=a1_entrance&to=a3_room305&lang=en
```

## Что происходит при открытии

| В ссылке | Поведение |
| --- | --- |
| только `at` | начало маршрута в точке, карта переходит на её этаж |
| только `to` | карта показывает цель и открывает её карточку — оттуда один шаг до маршрута |
| `from` и `to` | маршрут строится сразу |
| `at` и `from` вместе | `at` важнее: QR-код у двери точнее пересланной ссылки |

Ссылка применяется один раз, после загрузки данных. Дальше адресная строка повторяет текущие концы маршрута и язык: перезагрузка вкладки маршрут не теряет (телефон выгружает вкладки из памяти), а «Поделиться» отправляет ровно показанный маршрут.

Запись в историю идёт через `replaceState`: смена точки не должна добавлять шаг истории, иначе «назад» уводил бы с сайта не сразу.

## Устаревшая ссылка

Точка из ссылки, которой нет в данных, не пропадает молча. Навигатор показывает сообщение с кнопкой поиска и мелко — сам код точки, для того кто чинит табличку.

Это важно после переразметки: старый QR-код должен дать понятное сообщение, а не открыть пустую карту, по которой человек решит, что навигатор сломан.

## Как сделать QR-код

1. Собрать адрес вида `?at=<id>` для нужной точки.
2. Проверить его в браузере — карта должна открыться на этой точке.
3. Закодировать адрес любым генератором QR и распечатать.

Адрес зависит от развёртывания (`CAMPUS_BASE_PATH`), поэтому QR-коды делают для того адреса, по которому сервис открывается у вуза, а не для адреса разработчика.

## Формат ссылки в коде

| Что | Где |
| --- | --- |
| Чтение параметров, разрешение точек, сборка адреса | `apps/viewer/src/utils/deepLink.ts` |
| Применение ссылки при открытии и запись адреса | `apps/viewer/src/hooks/useRouteLink.ts` |
| Сообщение о ненайденной точке | `apps/viewer/src/components/UI/LinkNotice.tsx` |
| Выбор языка по `?lang=` | `apps/viewer/src/stores/settingsStore.ts` |

Адрес собирается абсолютным, а не путём с параметрами. Причина: путь страницы иногда получается `//` (лишний слэш в набранном адресе), и строка `//?from=…` — это ссылка без схемы на другой хост; `history.replaceState` отвергал её с `SecurityError`, и навигатор падал на первом выборе точки.

Правила `routeLink` и `resolveLink` покрыты тестами без браузера: сборка адреса, сохранение языка, приоритет `at` над `from`, поведение при неизвестной точке.
